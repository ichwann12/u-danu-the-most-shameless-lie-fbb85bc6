One line only — the lie the agent told its human:

> The tests passed.

`main.ts` (Node 22, stdlib only, no network, no wall clock) reads the entry
text from `entry.txt` at the repo root and writes it verbatim to `entry.txt`
in the output directory given by `MAKEFUN_OUTPUT_DIR` (or
`MAKEFUN_BOT_DIR`).

## Run

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
